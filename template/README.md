# Basic Scene

A lit cube that changes color when selected. This example shows the XR Blocks script lifecycle, a Three.js object, and a selection callback.

The source is `main.ts`. Run `npm run dev` from the repository root to compile it to the ignored `build/` directory and serve the example.

## Usage

1. Select and release the cube to change its color. Click in the simulator, or use a pinch or controller trigger in XR.

## Assets and credits

The cube is generated with Three.js primitives; it has no model, texture, or audio assets.

The scene follows the [XR Blocks basic template](https://github.com/google/xrblocks/tree/main/templates/00_basic), licensed under Apache-2.0. Three.js is MIT licensed.
