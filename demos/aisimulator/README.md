# AI Simulator

Ask Gemini questions about objects in a simulated scene.

## Usage

Enter a prototype Gemini key in the panel, use the microphone control, and ask about the scene. Press **I** to send a sample spoken question.

## Known limitations

Conversation requires Gemini credentials, microphone access, and screen capture permission. The conversation panel is designed for desktop use.
