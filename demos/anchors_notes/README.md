# Anchored Notes

Write notes and pin them to saved positions in a scene.

## Usage

Type a note and use **Pin** to place it. Reload to restore saved notes. Remove individual notes or use **Forget** to clear the saved content.

## Assets and credits

Application code and startup styles are copied from [XR Blocks](https://github.com/google/xrblocks), under Apache-2.0. Notes use SDK UI and generated scene geometry.

## Tested Devices

- Galaxy XR
- Simulator

## Known limitations

Desktop uses simulated anchors. Native persistence and text entry need checks on a compatible XR device.
