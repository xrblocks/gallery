# Anchored Gallery

Place shapes with saved positions and orientations. Restored content is shown in green.

## Usage

Use **Drop** to place a shape, then reload to check restore behavior. Use **Forget** to remove saved anchors.

## Assets and credits

Application code and startup styles are copied from [XR Blocks](https://github.com/google/xrblocks), under Apache-2.0. Shapes are generated with Three.js primitives.

## Tested Devices

- Galaxy XR
- Simulator

## Known limitations

Desktop uses simulated anchors. Persistent physical anchors require support from the XR device and browser; simulator restore is not proof of device persistence.
