# Magic Window

Use live person segmentation to change the camera backdrop and effects.

## Usage

Allow camera access when needed. Use the spatial controls to select a backdrop and adjust the effect.

## Assets and credits

Application code and startup styles are copied from [XR Blocks](https://github.com/google/xrblocks), under Apache-2.0. Segmentation uses the SDK's on-device vision pipeline. No Gemini key is required.

## Tested Devices

- Galaxy XR
- Simulator

## Known limitations

Camera and segmentation support depend on the browser and device. Model and SDK downloads need network access.
