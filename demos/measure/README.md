# Measure

Draw measuring tapes between points in an XR scene.

## Usage

Select and hold on a surface to start a tape, move the pointer to the other end, and release to finish. Repeat to measure another distance.

## Assets and credits

Application code and startup styles are copied from [XR Blocks](https://github.com/google/xrblocks), under Apache-2.0. Tape geometry is generated with Three.js.

## Tested Devices

- Galaxy XR
- Simulator

## Known limitations

Measurements depend on the available depth or simulator surface geometry. They are for prototyping, not precision measurement.
